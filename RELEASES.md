# Releases

The compiled MeteorRX package is distributed as a **GitHub Release**, not committed to the repository.

To publish a new version:
1. Build `MeteorRX-x.y.z-win64.zip` from the private source tree (`build_portable.bat`).
2. Draft a new Release here, tag `vX.Y.Z`, and attach that single zip.
3. Update `README.md` and `docs/USER_GUIDE.md` if needed.

Users download the zip, unzip anywhere, and run `MeteorRX.exe`.
