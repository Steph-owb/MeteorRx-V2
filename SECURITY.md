# Security & distribution policy

**Official source.** The only official MeteorRX download is the `MeteorRX-x.y.z-win64.zip` published on
this repository's **Releases** page. Do not run MeteorRX builds obtained anywhere else — they are not
authorised and may have been altered. If you received a copy from another source, please replace it
with the official release.

**Licence.** MeteorRX is free to use and test for amateur-radio purposes but may not be redistributed
(see `LICENSE`). Please link fellow operators here rather than sharing the file.

**Reporting a problem.** For bugs or reception issues, open an entry on the **Issues** page and attach
`data\meteorrx.log`. For anything you believe is a security concern, mark the issue accordingly.
